# Known issues

The only list of known defects; layer docs link here and do not keep their own. Rows were re-verified against master (commit aae38bde) by reading the code; nothing was reproduced on hardware or in simulation. Fixed issues are removed; see git history.

Severity is an estimate (high = wrong results, hang, memory-safety or build failure in a supported configuration; med = wrong behaviour in a corner case or non-default configuration; low = cosmetic, dead code, hygiene).

Status: `confirmed` = the defect was seen in the current code (brackets: what is still unproven); `unverified` = cannot be settled by reading the code (what is needed is in the row). "Caution" marks fixes that would break working code if applied naively.
